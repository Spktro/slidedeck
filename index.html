slidedeck

Framework de presentaciones HTML: tema claro/oscuro, selector de tamaño, navegador de miniaturas, copiar código y export a PDF.

Uso

Una slide es solo HTML

Escribís el contenido; el framework arma todo el resto.

Estructura mínima

<link rel="stylesheet" href="deck.css">

<div class="deck" data-brand="Mi charla">
  <section class="slide"> ... </section>
</div>

<script src="deck.js"></script>

Incluye solo

  • Tema claro/oscuro (recordado)
  • Selector de tamaño
  • Navegador de miniaturas
  • Botón copiar en el código
  • Teclado, clic y export a PDF

Atributos opcionales

AtributoDóndeQué hace

data-chapter.slideAgrupador mostrado en el navegador.
